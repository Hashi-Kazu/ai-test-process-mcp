# テスト設計: だんだん動物園入場システム(入場システムV03)

*本書はテスト分析書「だんだん動物園入場システムV03_テスト分析.md」で導出したテスト条件(55件)のうち、V02→V03差分に直結する高優先度の条件を中心に、`ai-test-process-mcp` の `design_boundary_values` / `design_equivalence_partitioning` / `generate_test_cases` ツールで境界値・同値クラス・テストケース仕様を生成した Test Design 成果物である。テストデザインコンテスト提出物としての性質上、全55条件・全網羅対象を尽くしたテストケース一式ではなく、最優先の17条件・20ケースを代表として骨格生成し、決定的検査（網羅率100%）を通したうえで残課題を明示する方針とした。*

---

## 1 境界値分析（design_boundary_values 実行結果）

テスト分析書2.2節 TC-010・TC-011・TC-012・TC-061・TC-073 の対象である「入場制限人数(時間枠あたり)」パラメータについて、V03での可変範囲(0〜999人、刻み1)を3値境界分析した。

### 変数: 入場制限人数(型: int, 範囲: 0〜999, 刻み: 1)

| 値 | 種別 | 有効/無効 |
| --- | --- | --- |
| -1 | 下限-刻み | 無効 |
| 0 | 下限 | 有効 |
| 1 | 下限+刻み | 有効 |
| 998 | 上限-刻み | 有効 |
| 999 | 上限 | 有効 |
| 1000 | 上限+刻み | 無効 |

**サマリ**: 総ケース数 6、有効4件／無効2件。

**設計判断**: V02の入場制限人数(30人)・V03の既定値(60人)自体は範囲の中間値であり境界値ではないため境界値分析の対象には含めず、代わりに範囲の下限(0)・上限(999)とその内外を対象とした。0人・999人はテスト依頼書に明記された「0〜999人の範囲でパラメータ変更可能」という要求を字義どおり検証する境界であり、-1・1000は「範囲外入力のバリデーション」というテスト条件TC-073（ガイドワード「範囲」由来）の根拠になる。

本書は55件のテスト条件のうち高優先度17件・20ケースを代表実装したものであり、以下は未着手である。次フェーズ（テスト設計改善／テスト計画書13.2「テスト設計改善」フェーズ）で追補する。
