## 2 取得によって判明した重要な事実

### 2.1 提出物定義（OPENクラス）

| | 内容 |
| --- | --- |
| 成果物1 | **テスト設計の最終成果物（最大40ページ）← メインの審査対象** |
| 成果物2 | テスト設計に関わる成果物一式（**FV表・NGT・マインドマップ・ゆもつよマトリクス**を例示） |
| 成果物3 | アピールシート（指定フォーマット） |
| 成果物4 | プレゼンテーション用資料 |
| 成果物5 | 決勝戦の展示資料（A3横・最大8ページ） |

成果物2で公式に例示されている3記法に本MCPは一つも対応していない → **#95**

### 2.2 審査基準の配点（決勝・成果物審査130点＋プレゼン15点）

| 審査項目 | 配点 | 現状 |
| --- | --- | --- |
| テスト要求分析 | 20点 | リソースは過去チーム相当以上 |
| **テストアーキテクチャ設計** | **30点** | **層が存在しない＝130点中30点(23%)を丸ごと落としている → #75 #83** |
| テスト詳細設計・実装 | 30点 | 17技法中4技法にしかエンジンがない → #74 ほか |
| 工程間一貫性 | 10点 | → #88 |
| 文書点（文書体系・保守性を含む） | 20点 | → #87 #94 #96 |
| 総合点（独自性・新規性を含む） | 20点 | → #76 |

### 2.3 訂正

当初この文書と #69 に「成果物2 = テストアーキテクチャ設計成果物（最大10ページ）」と記載していたが、**これはU-30クラスの定義でOPENクラスは異なる**。検索エンジンの要約を根拠にしたための誤りだった。訂正済み。

ただし結論は逆に強化された。テストアーキテクチャ設計は提出物の番号ではなく**審査基準の単独最大配点30点**として位置づけられている。
