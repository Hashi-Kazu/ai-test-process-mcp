# 2025年テストベース 仕様齟齬指摘

## 0. 本書の位置づけ

本書は `review_test_basis` の意味的レビュー用チェックリスト（`sample/2025/08_テストベースレビュー結果_2025テストベース.md` の
2章 TB-01〜TB-13）を適用して**人手で作成した文書であり、ツール出力そのままではない**。
したがって `sample/2025/00_成果物生成手順.md` 3.7 の**再現性 `diff` の対象外**である。

`review_test_basis` の入力は `documents` / `idPatterns` / `additionalAmbiguousTerms` の3キーだけであり、
生成済み markdown を入力に取る口を持たない。よって「自分の成果物に対して `review_test_basis` を実行する」ことは
仕様上できない。本書は「テストベース9文書に対して `review_test_basis` を実行し、その出力の意味的チェックリストを
人手で適用した結果」である。

指摘IDは **`SF-01` 以降**を使う。`sample/2025/07_要件分析結果_2025テストベース.md` 3章の指摘表が
ツール生成で `F-01`〜`F-189`（189件）を使い切っているため、記号を衝突させないためである。

### 0.1 該当箇所の表記

`該当箇所` は `文書名:行番号` 形式で示す。行番号は `.work/testbase/2025/*.txt`（`scripts/extract-testbase-text.sh` が
`pdftotext` で抽出したテキスト）の行番号であり、本調査では **poppler 24.02.0** を使用した。
poppler のバージョンが変わると改行位置が変化し行番号がずれる可能性がある（同一バージョンでの再抽出は完全一致することを確認済み）。

## 2. 決定的検査の限界（本書を必要とする理由）

`08_` の決定的検査の出力は**そのまま仕様欠陥として断定できない**。本調査で確認した具体例を記録する。

1. **`08_` 1.3 の「重複ID 144件」は144件の仕様欠陥ではない。** 大半は機能一覧と詳細記述の再掲、および画面仕様書での再定義である
   （1文書内の重複113件 / 文書間の重複31件）。**別機能への重複採番は `EH-100` / `EH-210` / `EH-900` の3ID（SF-01〜SF-03）だけ**である。
2. **`08_` 1.4 の未解決参照5件のうち、独立した仕様欠陥は1種のみ。** `S-003-0` は行折り返しによる偽陽性、`EH-241` ×2 は SF-04 と同一原因、
   残る `NH-500` ×2 が `EH-500` の誤記1種である（SF-11）。
3. **プレフィックスの意味的な系列違いは検出できない。** `EN-241`〜`EN-243`（SF-04）は `08_` 1.2 で独立プレフィックスとして整合しているため
   1.5 の逸脱に上がらない。1.5 が検出したのは `W` のセグメント数混在1件のみである。
4. **「書かれていないこと」は検出できない。** SF-07（入場ゲートハブのハードウェア仕様の不提供）・SF-08（`X.X.X` という未確定バージョン）・
   SF-09（Web側画面仕様に状態制限の記述が無い）・SF-10（反映タイミングの記述が無い）・SF-13（入場制限者数の値が無い）・
   SF-14（総台数の記述が無い）はいずれも記述の欠落であり、決定的検査の入口にならない。
5. **文書間の矛盾は候補として提示されるだけで、正誤は決まらない。** SF-05 は `07_` 2.2 の「日」行と `07_` 3章 F-157 が

   `idPatterns` を調整したり抜粋を投入したりしてはならない。
